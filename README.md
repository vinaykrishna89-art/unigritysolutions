# Unigrity Solutions website

Static marketing site. No build step.

## Local preview

```bash
cd unigrity-site
python3 -m http.server 8080
```

Then open http://localhost:8080

## Deploy (free)

Upload this folder to GitHub Pages, Netlify, or Cloudflare Pages. Point the host at the folder root (`index.html` at the top).

Before going live, replace the placeholder contact address and set absolute URLs in the Open Graph / Twitter image tags (search the HTML for `TODO`).
